# Protótipo Expo experimental

Este diretório contém o projeto Expo desenvolvido inicialmente por Ana Vitória para experimentar e demonstrar a interface do GoSilo.

## Finalidade

O projeto é mantido como referência visual e funcional para apoiar a compreensão das telas e dos fluxos da aplicação. Ele não representa a implementação oficial do frontend do grupo.

## Organização e manutenção

- Preserve os arquivos e as configurações originais do projeto.
- Mantenha aqui o `package.json`, os arquivos de configuração do Expo, os componentes, as telas e os recursos que fizerem parte do protótipo.
- Não misture as dependências deste projeto com as da implementação oficial localizada em `../src/`.
- Ao realizar alterações, registre o que foi modificado e mantenha a autoria original identificada.

## Execução

As instruções abaixo devem ser ajustadas conforme os arquivos reais do projeto:

1. Instale uma versão compatível do Node.js e do npm.
2. No terminal, acesse esta pasta.
3. Execute `npm install`.
4. Execute `npx expo start`.
5. Abra o projeto em um emulador compatível ou no aplicativo Expo Go, conforme a configuração utilizada.

Se os comandos ou requisitos forem diferentes no projeto original, prevalecem as configurações e instruções presentes nos arquivos dele.
