# Frontend — GoSilo

Este diretório reúne os materiais e o código relacionados à interface mobile do GoSilo.

## Organização

- `prototipo-experimental/`: projeto Expo desenvolvido inicialmente por Ana Vitória, mantido separadamente para demonstração e experimentação das telas.
- `src/`: espaço destinado à implementação oficial do aplicativo pela equipe, em React Native e JavaScript, respeitando os conteúdos estudados na disciplina.

## Diretriz de desenvolvimento

O protótipo experimental não deve ser considerado a implementação oficial do produto. Seus arquivos, dependências e configurações devem permanecer isolados em `prototipo-experimental/`.

A implementação oficial será construída gradualmente em `src/`. Funcionalidades que dependam de backend ou banco de dados devem ser documentadas como planejadas enquanto esses componentes não forem desenvolvidos.

## Como executar

Consulte o README de cada projeto. As instruções de instalação e execução do protótipo experimental devem ficar em `prototipo-experimental/README.md`. As instruções da aplicação oficial serão adicionadas quando ela possuir os arquivos necessários para execução.
