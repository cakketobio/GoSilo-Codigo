# Código-fonte do frontend oficial

Este diretório será utilizado para desenvolver a implementação oficial da interface mobile do GoSilo.

## Tecnologias previstas

- React Native
- JavaScript
- Expo, caso seja adotado na configuração oficial

## Organização prevista

- `assets/`: imagens, ícones e outros recursos visuais.
- `components/`: componentes reutilizáveis da interface.
- `data/`: dados locais e dados temporários utilizados durante o desenvolvimento.
- `navigation/`: configuração da navegação entre telas.
- `screens/`: telas organizadas por área do sistema.
- `styles/`: estilos, cores, tipografia e demais padrões visuais.
- `utils/`: funções auxiliares compartilhadas.

## Diretrizes

A implementação deve acompanhar o nível de conhecimento e os conteúdos trabalhados pela equipe na disciplina. Não adicionar funcionalidades como se estivessem concluídas quando ainda forem apenas protótipos ou propostas.

Integrações com API, autenticação real, persistência e comunicação em tempo real dependem das etapas futuras de backend e banco de dados.
