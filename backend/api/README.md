# API

Diretório destinado à organização da interface HTTP do backend, construída futuramente com FastAPI.

## Organização prevista

- `dependencies/`: dependências compartilhadas entre rotas, como mecanismos de autenticação e acesso a recursos.
- `routes/`: definição dos endpoints agrupados por funcionalidade.

As rotas deverão validar as entradas, acionar os serviços correspondentes e retornar respostas padronizadas. Esta estrutura é planejada e ainda não representa uma API implementada.
