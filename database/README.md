# Database — GoSilo

Este diretório está reservado aos materiais relacionados à modelagem e à futura implementação do banco de dados.

## Tecnologia prevista

- PostgreSQL
- PostGIS, para recursos que envolvam dados geográficos e localização

## Organização prevista

- `diagramas/`: diagramas e documentação da modelagem.
- `migrations/`: scripts de criação e alteração da estrutura do banco.
- `seeds/`: dados iniciais ou dados de exemplo para desenvolvimento.

## Situação atual

O banco de dados ainda não foi implementado. Os diretórios representam a organização planejada. A modelagem deverá ser alinhada aos requisitos, ao MER/DER e ao dicionário de dados antes da implementação.
